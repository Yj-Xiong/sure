分析单位

每个 sample_id × model candidate 形成一个条件点。听评者分数先汇总为 MOS，再与相同条件的客观指标计算 Pearson / Spearman。重复提交以同一任务、听评者、样本和候选的最新有效记录为准，原始提交仍保留。

只分析模型条件点的主客观相关性。reference 和 unprocessed 不进入相关性；不再拆分四类候选范围，也不生成方法两两或指标两两矩阵。

门控失败示例

objective row rejected

metric pesq 的 reference_mode=paired，但缺少 matching reference SHA-256。

Harness 不会用旧结果补这一行，也不会把该指标降级为 no-reference。

Agent 修复动作

读取 gate 错误→补齐配对 reference→重新生成 objective rows→再次校验

如果连续三次使用相同输入和相同错误，loop guard 会停止运行并要求人工修复。

为什么停下来

停止的目的不是阻止评测，而是防止错误文件继续进入后续统计。修复输入或重新生成产物后，可以通过 /sure_resume 从当前 checkpoint 继续，不需要从头开始。

失败、暂停和不完整都必须留下事件、诊断和已有产物；只有所有必要产物通过终态检查，运行才可以标记为 success。
